# Algorithms

## Classification

- ID3 decision tree
- J48 / C4.5-style tree
- K-nearest neighbours
- Naive Bayes
- Random Forest
- Support Vector Machine

## Clustering

- K-Means
- DBSCAN
- Hierarchical clustering

## Outputs

- Accuracy, precision, recall, F1, Kappa, MCC
- ROC/AUC and precision-recall curves
- Confusion matrix and detailed per-class report
- Decision-tree diagram, rules, leaves, and node count
- PCA cluster map, silhouette score, and cluster sizes
